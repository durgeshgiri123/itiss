# PKI (Public Key Infrastructure) — Complete Study Notes
### PGCP-ITISS | February 2026 Batch | ACTS, Pune (C-DAC)

These notes expand the official Teaching Guideline into exam-ready material. Each session file contains:

- **Detailed theory** (definitions, working, diagrams-in-text, comparisons)
- **Tricky/conceptual questions** (the kind that confuse students in exams)
- **Interview questions** with model answers
- **Quick-revision tables** for last-minute review

## How to use these notes
1. Read theory once, slowly, in order — concepts build on each other (e.g., you need symmetric/asymmetric encryption from Session 4 before hashing in Session 6, before digital signatures in Session 7).
2. Before your exam, revise only the **Quick Revision Table** and **Tricky Questions** sections of each file.
3. For interviews, the **Interview Q&A** sections use real phrasing interviewers use.

## Exam Weightage Reminder
- Theory exam: 40%
- Lab exam: 40%
- Internal Assessment: 20%

Lab-heavy sessions (5, 9, 10, 13, 14–15) deserve **equal or greater attention** than theory — many viva/lab-exam questions come straight from "why this step" reasoning (e.g., why import root CA into browser, why configure DNS for `.local` domains).
